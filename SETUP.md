# biltrax-cms — complete Laravel application source tree

## Requirements
PHP 8.2+, Composer, Node.js 20+, npm, MySQL 8+, and an AWS S3 private bucket for CV storage.

## Install in PowerShell
```powershell
cd biltrax-cms
Copy-Item .env.example .env
composer install
php artisan key:generate
npm install
npm run build
php artisan serve --port=8001
```
Set DB_* and AWS_* in `.env` before submitting forms. Both apps point to the existing `biltrax` database. **Do not run `migrate:fresh` or import the supplied dump over a populated database.**

## Notes
- The complete source tree includes `artisan`, bootstrap, routes, models, controllers, Vue views, config and public entrypoint. Composer's `/vendor` and npm's `/node_modules` are generated by install commands and are not included.
- The original HTML attachment is a self-unpacking bundle, not directly editable Vue SFC source; this package supplies a new Vue website interface rather than a pixel-perfect conversion.
- Protect credentials: do not commit `.env`. Configure an S3 private bucket with minimal IAM privileges.
- Do not deploy without testing upload/download, session/CSRF, accessibility and security controls.
